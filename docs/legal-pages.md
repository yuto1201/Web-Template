# 利用規約・プライバシーポリシー

すべての生成サイトに利用規約 `/terms` とプライバシーポリシー `/privacy` を必ず含めます。ログインの有無にかかわらず、共通フッターから両ページへ移動できる状態を保ちます。静的サイトや無料サイトであることだけを理由に省略しません。これはこのテンプレートの製品要件であり、すべてのサイトに同一の法的義務があるという説明ではありません。

## テンプレートの状態

- `src/app/terms/page.tsx` と `src/app/privacy/page.tsx` は、運営者が文面を作成するための**未確認のひな形**です。完成した規約や適法性の保証ではありません。
- `src/components/legal-document.tsx` が未確認表示と未確定日付を表示します。ドラフトのページタイトル・説明・`robots` は公開前に見直します。`noindex` は閲覧制限ではありません。
- `src/components/site-footer.tsx` を root layout に配置しています。ホーム、ログイン、アカウント、法務ページで共通の導線になります。
- `src/proxy.ts` はこの2つの完全一致パスだけを認証セッション更新から除外します。Cookie、DB、ログイン、Supabase接続に依存する処理を法務ページへ追加しないでください。`/account` の保護は維持します。

## 公開前チェックリスト

公開を担当する Issue で、以下を確認して運営者の確認日・対象文書・未解決事項を記録します。文面の確定はサイトごとの判断です。不明点は未確定とし、必要に応じて適切な専門家に確認してください。

- [ ] サービス名、運営者の正式名称、必要な所在地・代表者情報、連絡可能な問い合わせ窓口を確認する。GitHubやクラウドのアカウント情報を運営者情報として自動転記しない。
- [ ] 利用規約を実際の機能・対象年齢/地域・登録・禁止事項・投稿権利・サービス停止/終了に合わせて作成する。課金がある場合は料金・更新・解約・返金も確認する。責任制限・同意方法・改定通知・紛争対応を一律に断定しない。
- [ ] 取得情報・取得方法・目的、認証Cookie、アクセスログ、保存期間/判断基準、削除・バックアップ、安全管理措置、問い合わせ/開示等の手続を実装・運用と照合する。
- [ ] 実際に利用する解析・広告・決済・メール・ホスティング等、送信情報、委託/第三者提供、国外での取扱いを確認する。未導入サービスを利用中と書かず、不要と確認できた項目も実態を説明する。
- [ ] 対象地域・年齢・データの扱いに応じた追加表示や同意の必要性を確認する。リンクがあることは同意取得の証拠ではない。必要な同意機能などは別途実装・検証する。
- [ ] 両文書の整合を確認し、施行日・最終更新日を確定する。確認項目の文章を利用者向けの確定文書に置き換え、未確認表示とドラフト用メタデータを更新する。
- [ ] ログアウト状態で `/terms` と `/privacy` が読め、ホーム・ログインから両リンクが機能することをモバイル/デスクトップ・キーボード操作で確認する。

日本向けの個人情報の取扱いを確認する際の一次資料は、[個人情報保護委員会の通則編ガイドライン](https://www.ppc.go.jp/personalinfo/legal/guidelines_tsusoku/)です。利用目的や保有個人データに関する事項などを実態に合わせて確認してください。このチェックリストは法域ごとの網羅的な法務審査ではありません。

## 検証と引き継ぎ

`npm test -- tests/legal-pages.test.tsx tests/legal-proxy.test.ts` はページの存在、共通リンク、法務ページの設定不要境界を検査します。`npm run test:e2e` はHTTP到達・リンク移動・アクセシビリティ・画面幅を検査し、`npm run template:verify` は別名の生成先でも実行します。

生成先で文面や言語を確定したときは、ドラフト固有のタイトル・警告・日付のテスト期待値を同じ Issue で更新してください。ルート存在、未ログインでの閲覧、共通リンク、秘密情報境界の回帰検証は削除しません。

Bootstrap完了は、両ページとリンクを継承し、アプリ固有の確認項目と未決事項を仕様へ引き継いだ状態です。`readiness`、ビルド、テスト成功は、文面の正しさ・法的有効性・公開承認を保証しません。公開前チェックは運用上の必須ゲートであり、自動デプロイを止める技術的なインターロックではありません。未確認ドラフトを本番文書として扱わないでください。
